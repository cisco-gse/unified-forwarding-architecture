# unified-forwarding-architecture

## Requirements

#### Scale
* Massive scale
* IPv6
* Entropy
* Keep it simple

#### Segmentation/VPN
* L3VPN
* L2VPN
* Static / P2P tunnel
* IPN (Isovalent Private Network) - Overlay that can span K8s and VMs

#### Micro-segmentation
* Security group
* Identity

#### Extensibility - I can do innovative things with my network
* What service or capability do you wish your network could deliver?

#### Path manipulation
* TE
* SLA
* Security
* Sovereignty
* Service Chain
* Packet spraying
* Load balancing
* Path probing

* Campus
* Branch
* Access
* IoT
* WAN
* Internet
* SP Transport
* DC (frontend and backend)
* Scale-up
* Scale-out
* Scale-across
* Cloud
* VPC/virtual networks
* Transit Gateway, Ingress/Egress Gateway
* Host network stacks (Linux, Kubernetes)
* SmartNICs
* CNIs
* DPUs
* Security appliances
* Security services (SASE)
* Distributed security fabric (Hypershield/Tetragon/eBPF)
* Broadband and Mobile subscriber gateways (BNG, UPF)
